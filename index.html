Problem & Approach

Urban highway traffic is inherently interconnected: vehicle flow at any detector depends on its own prior trajectory, upstream congestion shockwaves, and recurring diurnal rush hour patterns. This model jointly captures temporal self-attention and topological graph diffusion to predict real California freeway flow across all 170 detectors simultaneously.

Factorised Spatiotemporal Transformer Architecture

Decoupled spatial and temporal self-attention operators with linear complexity $O(N)$ and physical road diffusion priors.

1. Multimodal Input
12 timesteps × $N$ detectors × vehicle flow feature vector.
→
2. Joint Embeddings
Flow value + Time-of-day (0–287) + Day-of-week (0–6) + Spatial Node IDs.
→
3. ST-Transformer Blocks (×3)
Temporal Multi-Head Attention → Linear Kernel Spatial Attention + Graph Diffusion.
→
4. Delay Propagation
Shockwave velocity kernel ($v_w \approx 18$ km/h) over highway distance topology.
→
5. Direct Head
Multi-step projection outputting 12 future steps simultaneously.
Why Linear Spatial Attention? Standard Transformer self-attention computes an $N \times N$ attention matrix ($O(N^2)$ memory), which crashes GPU memory when monitoring large statewide metropolitan networks (thousands of sensors). Our model leverages positive kernel feature maps ($\phi(x) = \text{elu}(x) + 1$) to invert the attention multiplication order: $(Q K^T) V = Q (K^T V)$, reducing spatial attention to linear $O(N)$ complexity!

Honest Limitations & Future Engineering

  • Single Highway Dataset Scope: Current benchmark weights are trained on Caltrans PeMS08 (170 detectors on California I-10 and I-15). Urban arterial streets with signalized intersections feature stop-and-go dynamics distinct from uninterrupted freeway flow.
  • Speed vs. Flow Targets: The trained model targets Traffic Flow (vehicles / 5-min). Third-party APIs (such as TomTom) predominantly broadcast Probe Velocity (km/h). Feeding probe speeds directly into flow-trained models produces metric invalidity; dedicated velocity checkpoints are required for speed forecasting.
  • Sparse Graph Scaling: While linear attention reduces attention memory to $O(N)$, the static graph diffusion step currently uses dense adjacency representations. Full scaling to 10,000+ detectors will adopt `torch.sparse` graph operations.
